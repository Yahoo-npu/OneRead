# 一读 · One Read v1.0.0

macOS 英文读物阅读器，支持双语对照、划词学习和长难句解析。

## 下载

- 系统：macOS 14 或更高。
- 芯片：Apple Silicon（M 系列）。此安装包不适用于 Intel。
- 安装：下载 `OneRead-v1.0.0-macos-arm64.zip`，解压后将 App 拖入“应用程序”。
- 校验：将 `SHA256SUMS.txt` 和 ZIP 放在同一目录，运行 `shasum -a 256 -c SHA256SUMS.txt`。

## 功能

- PDF / EPUB 图文阅读、双语对照滚动、句子联动、章节和全文翻译。
- 划词浮窗、美式音标与朗读、单词原形和文中释义。
- 鼠标停留句子，⌘T 查看成分、从句和语法分析。
- 生词按书籍查看、归档、考试参考词表标签，手动追加同步到墨墨。
- 经济学人、纽约客、The Atlantic、Wired 期刊导入与启动新刊提醒。
- 分类书架、九宫格封面、最近阅读、已读进度和最近删除。
- 可调宽、可折叠每日一言；主题、字号及本地数据迁移。

首个公开发行版本，采用正式极简图标，提供完整使用文档、可视化 README 及发布脚本。

## 使用说明

先导入读物，在“设置 → 翻译服务”填写自己的 API Key 或配置已登录的本地 CLI，测试通过后保存。没有内置共享 Key。保存的译文可离线阅读。

当前构建为临时签名、未经 Developer ID 公证，首次打开可能需在 macOS“隐私与安全性”中确认。升级前先退出旧版本。

考试词表是社区参考数据，模型释义与语法分析可能有误；扫描 PDF 没有内置 OCR。外刊下载和新刊检查受 GitHub 与网络状况影响。自动化测试使用模拟服务；真实大文件下载曾遇到超时，需根据本机网络验证。

详见仓库 README 与完整使用指南。
