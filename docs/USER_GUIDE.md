# 使用指南

[返回首页](../README.md)

## 安装与第一次打开

从 [Releases](https://github.com/Yahoo-npu/OneRead/releases) 下载适合你电脑的安装 ZIP，解压后拖入“应用程序”。当前已准备的安装包为 Apple Silicon 版，要求 macOS 14+。源码包需要自行构建。

开发版未公证，首次打开可能需要在 macOS“隐私与安全性”里确认。仅打开你信任来源的文件。升级前先退出旧版，替换应用不会主动删除独立存储的书库。

## 书架与分类

- **导入读物**：选择一个或多个无 DRM 的 PDF / EPUB。原文件和图片会保存进应用的数据目录。
- **导入外刊**：顶部切换经济学人、纽约客、The Atlantic、Wired，按年份或日期筛选，点击“导入本期”。若已在书架，按钮会变成“打开”；若在最近删除中，可恢复。
- **最近阅读**：点击卡片继续阅读；“查看全部”按最近打开的时间展示记录。
- **新建分类**：点击书架右上角新建图标，为分类命名。在书籍右键菜单中选择“移入分类”。分类封面按加入时间展示最近 9 本读物的封面。
- **编辑 / 删除分类**：右键分类卡片操作。删除分类仅将读物移回未分类，保留书籍、阅读状态和生词。
- **封面大小**：右上角三种网格图标分别对应小、中、大。
- **删除书籍**：书封垃圾桶或书籍右键菜单 → 删除书籍。书籍先进入“最近删除”，支持恢复、单本彻底删除和一键清空；彻底删除无法在应用内恢复。独立生词记录仍保留。
- **每日一言**：拖动名言区左边的分隔线调宽度；书架右上角侧栏按钮折叠或展开。每天更换一次，重启会记住宽度和折叠状态。

外刊会在每次启动时检查更新。提醒中的“导入本期”需你确认；“暂不导入”记录当前期号，更晚一期仍可提醒。关闭应用后不在后台持续检查。当前网络或 GitHub 限流时，仍可查看缓存目录，点击“刷新”稍后重试。

## 配置翻译

打开右上角滑杆设置图标，左侧选择 **翻译服务**。

### 云端 API

1. 接入方式选“云端 API”。
2. 选择服务商，填写该服务商签发的 API Key。
3. 选择模型；可刷新可用模型列表，或手动填写模型 API ID。
4. 点击“测试翻译连接”，成功后点击“完成”。

切换服务商会保留各自配置。预置服务填写接口地址；自定义兼容 API 可以输入服务商给出的地址和模型 ID。网页订阅与 API 的计费、权限并不必然相同，以服务商规则为准。

连接失败时：401 通常表示 Key 或服务商不匹配；404 检查地址和模型 ID；429 表示请求限流；5xx 或超时请检查服务状态和网络。请勿在反馈截图中展示密钥。

### 本地 Agent

1. 在终端安装并登录你选择的 CLI。
2. 接入方式选“本地 Agent”，点击“检测本地 Agent”。
3. 选择检测结果，测试连接后保存。

支持检测 Codex CLI、Claude Code、Gemini CLI；也可填自定义可执行程序路径及参数。参数按行填写，不通过 shell 拼接。检测成功只说明找到了程序，仍需确认登录和模型可用。自定义适配器接受标准输入中的提示词，通过标准输出返回结果。

## 阅读与翻译

顶部选择 **仅原文 / 原文译文 / 仅译文**。双栏模式下可拖动中间分隔线调节宽度，使用两栏交换按钮改变顺序。滚动联动与句子悬停高亮用于定位对应原文、译文。

左侧 **目录** 展示章节层级，可展开、折叠，目录标题会使用配置的翻译服务翻译。标题右侧小圆圈可切换已读状态；**已读** 页仅显示已标记文章。阅读进度由已读标记计算，不由滚动距离或翻译完成率计算。

- **翻译本章**：处理当前章节未翻译的内容。无书签 PDF 通常按页显示“翻译本页”。
- **停止翻译**：停止当前任务，已保存部分保留，可稍后继续。
- **更多（…）→ 翻译全文**：处理整本未完成部分，可能产生较多模型请求。
- **更多 → 重新载入原文**：重新解析源文件，尽可能保留能匹配的译文和阅读状态。
- **画笔图标**：调整主题与正文字号，目录字号相应变化。
- **插图**：点击可放大。原文中的内嵌图片在导入时本地保存，外链图片不自动下载。

## 划词和长难句

拖选或双击单词，浮窗显示美式音标、词性、文中含义、解释、其他释义，以及有变形时的原形。点击喇叭朗读；“加入生词本”收藏。点击空白、滚动或按 Esc 可收起浮窗。

**长难句解析**：把鼠标停留在需要分析的句子上，按 **⌘T**，浮窗展示翻译、句子成分、从句及重点语法。无需先拖选整个句子。

内容由模型生成，遇到不合理的释义、音标或分析时可重试，并结合原文判断。朗读使用系统英语语音，不需要额外语音 API。

## 生词本与墨墨

点击“生词本”，可搜索单词、释义或出处，按来源书籍筛选。每行显示单词、音标、朗读、词性和文中释义，下一行显示书籍、文章与加入时间。

- 归档适合收纳已掌握词汇；归档词仍参与墨墨同步。
- 右侧更多菜单可调整书籍分类或删除生词。
- CET-4、CET-6、考研、IELTS、TOEFL 标签表示内置参考词表收录情况，点击“词表说明”查看来源；未匹配不代表考试不考。
- 当前不提供独立手动录入单词入口，请从阅读浮窗中收藏。

同步墨墨：

1. 在设置的“墨墨同步”页填写自己的开放 API Token，保存。
2. 返回生词本，点击“同步墨墨”。首次同步创建云词本，之后继续追加。
3. 同步包括全部本地生词，不受书籍筛选或归档状态影响；保留云端已有词，不上传本地释义、出处和例句。

同步为手动单向追加。删除本地词不会删除云端词。若创建词本请求超时，请先检查墨墨云端是否已创建，避免重复操作。

## 数据位置与备份

默认数据目录为 `~/Library/Application Support/OneRead/`。设置 → 本地数据可直接输入完整绝对路径或以 `~` 开头的路径，也可通过“选择文件夹”填入，再点击“应用路径”。选择的文件夹直接作为数据根目录，不会额外追加子文件夹。

新位置不能覆盖已有目录，不能是当前目录的子目录或祖先目录。迁移会复制现有数据，验证后切换，原位置副本不自动删除。再次应用当前路径不会重复迁移。

备份前先退出应用，将整个数据目录复制到安全位置，包括 `library.json`、`Assets/` 和可选的 `FolderCovers/`。API Key 与墨墨 Token 在钥匙串中，不包含在这份普通文件备份里。切勿把自己的数据目录上传到本项目仓库。

## 常见问题

**下载了 ZIP，但找不到 App？** 确认下载的是 `OneRead-v版本-macos-arm64.zip`，不是 GitHub 的 Source code。

**PDF 图片正常，但选不了词？** 扫描 PDF 可能没有文字层；目前没有内置 OCR，需要先识别文字。

**新刊列表加载不出来？** 网络、仓库或 GitHub 限流可能暂时影响检查；缓存目录仍可浏览，稍后刷新。

**标题没有译文？** 先配置可用的翻译服务，点击目录附近的翻译按钮重试。

**升级后找不到旧书库？** 先核对“本地数据”页路径。不要把空书库覆盖到旧 `library.json` 上。

**模型结果不正确？** 换用其他可用模型或重新查询。模型输出不保证准确，考试标签也不是官方考纲认定。
