# 一读 · One Read 官网

纯白底色、灰绿色主色、杂志式文字排版与细线插画。首页保留应用真实书架截图；功能区参考用户提供的七段操作录屏及应用源代码，以 HTML、CSS、SVG 和 JavaScript 重建为自动播放的功能动画。

官网源文件位于 `website/dist`，发布副本位于 `website_dsh`。更新后需同步这两个目录；推送到 `main` 后，现有 `.github/workflows/static.yml` 会将 `website_dsh` 部署至 GitHub Pages。

## 本地查看

可直接双击 `dist/index.html`，不需要联网、构建或安装依赖。也可从项目根目录运行：

```bash
python3 website/scripts/preview.py
```

访问 `http://127.0.0.1:4173`，按 `Ctrl+C` 停止。

## 七个功能动画演示

| 场景 | 动画展示内容 |
| --- | --- |
| 外刊导入 | 打开外刊列表，切换四种刊物，选择期号并加入示例书架 |
| 新刊推送 | 点击新刊提醒中的“导入本期”，完成导入后直接进入该期阅读界面 |
| 双语对照 | 滚动任意一栏，联动另一栏；点击或移过句子，高亮对应译文；切换阅读模式 |
| 一键翻译 | 点击“翻译本章”，逐段生成预设译文，保留示例插图 |
| 划词翻译 | 点击或选中 antitrust，打开词卡、查看文中释义并加入演示生词本 |
| 长难句解析 | 点击示例长句，滚动查看中文译文、句子主干、句子成分、从句分析和重点语法 |
| 墨墨同步 | 查看来源书籍，搜索、归档与按书籍查看，体验同步进度与完成反馈 |

界面使用固定的 1360 × 848 Mac 窗口比例整体缩放：工具栏参考 `App.swift`，外刊导入参考 `MagazineImportView.swift` / `EconomistView.swift`，阅读、词卡和连续滚动式解析参考 `Reader.html`，生词本参考 `WordsView.swift`。小屏保留 Mac 布局，支持横向滑动；不把桌面布局改造成另一套移动界面。

所有演示是本地预设的交互示意，不调用翻译 API、GitHub 外刊仓库或真实墨墨账户，也不会读取用户书库。期号、词汇和句法解析用于演示。封面、插图及阅读片段从用户授权的本地书库提取，仅导出展示所需的内容，不复制书库路径、内部 ID 或任何配置、密钥。网页朗读仅在浏览器有本地美式英语语音时提供；不可用时显示说明，不请求外部语音服务。⌘T 是 OneRead 应用内快捷键，网页仅播放预设动画，不接收阅读器内的用户操作。

默认依次演示七个流程，最后一个结束后从头开始。点击顶部标签切换为该功能的单项循环；演示画布设为 inert 并禁用指针输入，不接受点击、输入、选词或内部滚动，放大后同样仅供观看。“全部连播”从当前功能重新开始连续演示。

离屏、切换浏览器后台时暂停轮播计时；系统“减少动态效果”模式下展示静态初始状态，仍可切换场景查看静态预览。放大窗口直接移动同一份网页界面，保留操作状态，不重复创建演示。没有视频播放控件、视频下载或图片序列。

## 页面交互

- 首屏真实书架随指针轻微倾斜，触控及减少动态效果模式关闭倾斜。
- 已移除独立的中英文短语联动展示区，双语体验保留在功能演示中。
- 四刊整张卡片支持点击、Enter / Space 翻转，背面介绍刊物与适读人群；减少动态效果时即时切换。
- 读者区使用约 96–112px 的三幅墨线读者速写，搭配身份标签与阅读场景文案。当前资源为 `dist/assets/reader-sketches.png`，通过 CSS 分栏展示，小屏改为单列；旧版大幅插画保留但不再引用。
- 四刊使用现有书库演示中的真实封面 `dist/assets/native/cover-{0,1,2,3}-0.webp`，完整展示比例，版权归各刊物权利人；仅为封面示例，不代表最新期刊。
- 所有下载按钮统一跳转至下载区，Mac 保留现有发布链接，Windows 与 Android 显示“即将上线”。下载区将 Mac 主入口与 Windows / Android 待上线信息分为两级展示；上线时为对应 `.download-future` 添加真实下载链接并更新状态文案。
- 功能标签有平滑选中标记；窄屏自动把活动标签移入可见范围。
- 离开首页后导航自动收起，返回恢复；章节入场、四刊阅读方向和 FAQ 带轻量过渡。
- 使用说明采用顶部横排三步入门、完整指南入口和下方紧凑问答列表；小屏步骤纵排，问题支持点击展开。
- 开源鸣谢采用统一的细线图标与项目卡片，保留项目、许可证及声明链接。
- 保留 GitHub、下载、完整使用指南和开源鸣谢链接。

## 文件结构

- `dist/index.html`：页面内容、演示容器与放大窗口。
- `dist/style.css`：页面版式与响应式样式。
- `dist/native-demo.css`：可交互的阅读器、词卡、导入面板和生词本样式。
- `dist/native-demo.js`：七种场景与预设内容、动画步骤及清理逻辑。
- `dist/native-content.js`：展示所需的期刊封面信息和原文、译文片段。
- `dist/main.js`：自动轮播、场景标签、放大窗口、导航和展开交互。
- `dist/studio.js`：标签指示器、首页轻微倾斜。
- `dist/assets/`：本地图标、首页截图与经过缩小压缩的期刊封面、插图。演示不需要视频资源。
- `tests/native-playlist.cjs`：轮播、手动打断、离屏暂停、放大状态保持和减少动态效果回归检查。

运行检查：

```bash
node website/tests/native-playlist.cjs
node website/tests/demo-pointer.cjs
node --check website/dist/native-demo.js
node --check website/dist/main.js
```

## 录屏参考与来源

七段原始 MOV 位于用户指定的 `~/Desktop/功能演示/`，保持原样。此前转封装的 MP4 与视频封面已移至项目 `.local/website-video-reference/demos/`，不包含在网站交付包中。历史录屏处理脚本保留在 `scripts/`，供需要时使用。

页面底部保留 reader、awesome-english-ebooks、english-vocabulary、ECDICT、Project Gutenberg 及完整第三方声明的鸣谢链接。交互布局参考本项目的原生应用实现；演示中的文章、插图和封面版权归各权利人。无外部字体、图标库、前端框架或 CDN 运行时依赖。

模拟鼠标移动用时 360ms，到达目标后在同一任务中显示单次点击光圈并执行界面操作；光圈 420ms 后清除，不再循环。场景销毁时清理待执行步骤，避免旧场景点击残留。
