# 一读 · One Read — 官网设计方案 B「一本书的旅程」

为「一读 · One Read」设计的第二个官网方案，存放在独立的 `website_dsh/` 目录中。**未改动 `website/` 中的原设计方案**，仅复用了其中的素材文件（应用图标、真实书架截图、七段实机录屏与封面海报）。

## 设计概念

把整个网站做成**一本书的旅程**：封面（首屏）→ 七个功能演示 → 四刊 → 尾声 → 下载 → 附录。

- **纯白底色**：页面底色为纯白 `#ffffff`，用细线（hairline）与留白建立层次；主色沿用应用品牌的森林绿 `#456d52` 与低饱和红 `#a94c57`。
- **只用真实素材**：七个功能演示全部为用户提供的实机录屏（静音、原速、不重新编码），视频直接融入页面，没有窗口外壳、悬浮控件或自行设计的示意内容；主界面配图使用真实书架截图。
- **简洁优雅**：衬线标题、等宽编号、克制动效；无顶部目录栏、无外部字体/图标/框架。演示区采用左侧文本、右侧录屏的两栏排版，控制整页高度与节奏。

## 页面结构

| 区块 | 内容 | 交互 |
| --- | --- | --- |
| 封面 | 口号 + 真实书架截图 | 截图随指针轻微 3D 倾斜；三枚细小定位点悬停展开说明；打字机轮播三句英文 |
| 功能演示 | 七段实机录屏，逐段单独展示（左文右屏） | 进入视野自动静音循环播放、滚出暂停；「减少动态效果」下改为点击播放 |
| 四刊 | 经济学人 / 纽约客 / The Atlantic / WIRED 线稿卡片 | 悬停抬升；点击**真正翻页**（3D 翻转）查看「适合练习」内页，键盘可返回 |
| 尾声 | 三类读者 + 装饰性「一」字水印 | 行悬停时编号、图标与箭头联动 |
| 下载 | macOS / Windows / Android 三平台卡片 | 顶栏下载按钮展开平台菜单（行错峰入场，键盘可达）；macOS 可下载，Windows 与 Android 显示「即将推出」 |
| 页码标记 | 右下角 P.0X / 05 | 随章节滚动翻动数字，点击回到顶部 |
| 附录 | FAQ 手风琴、致谢与页脚 | 同组只展开一个 |

**无障碍**：下载菜单支持键盘操作与 `Esc` 关闭；跟随系统「减少动态效果」；触摸设备降级为点击；无 JavaScript 时保留全部静态内容与 macOS 下载链接。

## 滚动与动效性能

- **无实时毛玻璃**：页眉使用纯白不透明底色，避免滚动时逐帧重新采样背景。
- **进度条合成层缩放**：进度条改用 `transform: scaleX()`，滚动时不再触发布局与重绘。
- **自定义锚点滚动**：页面切换使用距离自适应时长（420–950ms）与缓入缓出曲线，滚轮 / 触摸可随时接管；滚动期间暂停视频。
- **单视频解码**：只播放当前最可见的一段录屏，其余立即暂停，避免多段同时解码掉帧。
- **渐入优化**：提前 6% 触发、缩短至 0.55s、位移 14px，且不再对整块视频区域做透明度动画；封面倾斜改为 rAF 节流并关闭移动中的过渡。
- **翻页细节**：四刊卡片 3D 翻转；锚点抵达时区块顶部画一道红色页边线；右下角页码随章节翻动；录屏真正播放时「实机演示」状态点亮红点。全部只使用 `transform / opacity`，并尊重「减少动态效果」。

## 下载平台接口

平台状态集中维护在 `app.js` 顶部的 `PLATFORMS` 配置中：

```js
const PLATFORMS = {
  macos:   { status: 'ready', href: 'https://github.com/Yahoo-npu/OneRead/releases/latest', tag: 'v1.0.0 ↓', cta: '下载 v1.0.0' },
  windows: { status: 'soon', tag: '即将推出' },
  android: { status: 'soon', tag: '即将推出' }
};
```

上线新平台时，把对应项的 `status` 改为 `'ready'`、填入 `href` 与 `cta`，页面中所有 `[data-platform]` 元素（顶栏菜单行与下载区卡片）会自动切换为可点击状态：菜单行获得链接与版本号，卡片显示下载按钮并隐藏「即将推出」标签。Windows 与 Android 的预留按钮与链接已就位，届时不需改动页面结构。

## 本地预览

```bash
python3 website_dsh/scripts/preview.py
```

访问 `http://127.0.0.1:4174`（服务器只监听本机，支持视频字节范围请求；也可直接双击 `index.html`）。按 `Ctrl+C` 停止。

## 文件结构

- `index.html` — 页面语义结构（无外部依赖）
- `style.css` — 纯白底色的统一视觉系统、响应式与减少动态效果适配
- `app.js` — 进度细线、导航高亮、渐入、打字机、封面倾斜、四刊卡片、FAQ、下载菜单与平台配置、录屏的可见即播
- `assets/` — 从 `website/dist/assets/` 复制的素材（app-icon、library.webp、七段 MP4 与 WebP 封面、manifest.json）
- `scripts/preview.py` — 支持 Range 请求的本地预览服务器
